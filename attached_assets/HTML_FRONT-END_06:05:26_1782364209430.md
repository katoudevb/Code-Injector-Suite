# 🌐 HTML

> Langage de balise (textes, liens, images…). Les balises de structure sont la base à utiliser pour tout projet.
> 

---

## Base de page HTML sémantique

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Base page HTML sémantique</title>
</head>
<body>

<header>
  <h1>Mon site</h1>
  <nav aria-label="Navigation principale">
    <ul>
      <li><a href="#">Accueil</a></li>
      <li><a href="#">Articles</a></li>
      <li><a href="#">Contact</a></li>
    </ul>
  </nav>
</header>

<main>
  <section>
    <h2>Section 1</h2>
    <p>Contenu de la section 1...</p>
  </section>

  <article>
    <h2>Article 1</h2>
    <p>Texte de l'article...</p>
  </article>

  <aside>
    <p>Informations complémentaires ou encadrés</p>
  </aside>
</main>

<footer>
  <p>© 2026 Mon site - Mentions légales</p>
</footer>

</body>
</html>
```

## Types de balises

| Type | Exemple | Description |
| --- | --- | --- |
| Associer | `<a>... <b>...</b></a>` | Balises imbriquées |
| Orpheline | `<c ... />` | Balise sans fermeture |
| Paire | `<d>...</d>` | Balise ouvrante + fermante |

---

## Base universelle d’une page web

**Éléments communs à toutes les pages :**
- Header (en-tête) : logo, menu de navigation
- Footer (pied de page) : contacts, liens utiles, mentions légales
- Styles et polices globales (CSS)

**Éléments spécifiques à chaque page :**
- Titre de la page
- Contenu principal (texte, images, médias)
- Image ou visuel principal (facultatif)

## Les balises


### Citations

```html
<!-- Longue citation -->
<blockquote>
  "Le code est comme l'humour. Quand il faut l'expliquer, c'est qu'il est mauvais."
</blockquote>

<!-- Citation courte inline -->
<p>Comme le dit Linus Torvalds : <q>Talk is cheap. Show me the code.</q></p>

<!-- Citation avec auteur -->
<blockquote>
  "Talk is cheap. Show me the code."
  <cite>Linus Torvalds</cite>
</blockquote>
```

```html

```


## Guide de style

### Structure du document

- Toujours inclure `<!DOCTYPE html>`
- Déclarer l’encodage : `<meta charset="UTF-8">`
- Indentation cohérente (2 espaces recommandés)
- Arborescence logique : `<header>` → `<nav>` → `<main>` → `<section>` → `<footer>`

### Nommage et attributs

- Attributs en minuscules, valeurs entre guillemets doubles `" "`
- Classes en kebab-case : `main-header`
- Ordre des attributs : `type` → `id` → `class` → autres
- IDs uniques dans le document

### Sémantique HTML5

- Utiliser les balises appropriées : `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- Éviter les `<div>` ou `<span>` inutiles
- Titres hiérarchiques : `<h1>` → `<h2>` → `<h3>`

### Accessibilité (a11y)

- Toujours ajouter `alt` aux images : `<img src="logo.png" alt="Logo">`
- Lier `label` à `input` via `for` : `<label for="email">Email</label>`
- Utiliser ARIA si nécessaire : `<button aria-expanded="false">Menu</button>`
- Spécifier la langue : `<html lang="fr">`

### Lisibilité et organisation

- Retour à la ligne après chaque balise importante
- Commentaires pour séparer les sections : `<!-- Section : Header -->`
- Ne pas mettre de style inline dans les balises

### Performances

- Placer `<script>` à la fin du `<body>` (sauf modules)
- Minifier HTML pour la production
- Charger les polices via `<link rel="preconnect" href="https://fonts.googleapis.com">`

### Formulaires

- Grouper les champs avec `<form>` et `<fieldset>` si nécessaire
- Boutons avec `type="submit"` explicite : `<button type="submit">Envoyer</button>`

### SEO

- Meta description présente et descriptive : `<meta name="description" content="Page de contact">`
- Balise `<title>` unique et explicite
- Liens internes cohérents avec la structure du site

### Bonnes pratiques générales

- Pas de texte brut dans `<body>` sans balise
- Grouper liens similaires dans `<ul><li>`
- Maintenir une arborescence et un code lisibles et cohérents
