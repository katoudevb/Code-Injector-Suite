## Sélecteurs 📌

```
/*─── Schéma des types de sélecteurs ───*/

balise            → Cible une balise HTML (ex: p, h1, div)
.class            → Cible une classe CSS
#id               → Cible un identifiant unique
baliseA baliseB   → Descendant (baliseB à l'intérieur de baliseA)
baliseA > baliseB → Enfant direct uniquement
baliseA + baliseB → Adjacent (juste après baliseA)
baliseA ~ baliseB → Frères généraux (tous après baliseA)
*                 → Universel (tous les éléments)
[attribut]        → Balise avec attribut
[attribut=val]    → Balise avec attribut + valeur précise
:hover            → Pseudo-classe : survol souris
:active           → Pseudo-classe : clic en cours
:focus            → Pseudo-classe : élément sélectionné
:visited          → Pseudo-classe : lien déjà visité
::first-line      → Pseudo-élément : première ligne
```

```css
/*Avec tag (balise)*/
balise { proprieter : valeur; }

/*Avec classe*/
.class { proprieter : valeur; }

/*Avec id*/
#id { proprieter : valeur; }

/*Avec plusieurs balises (descendant)*/
baliseA balise B { proprieter: valeur; }

/*Avec plusieurs balises (enfant direct)*/
balise A > balise B { proprieter : valeur; }

/*Avec plusieurs balises (adjacent)*/
baliseA + balise B { proprieter : valeur; }

/*Avec plusieurs balises (frère généraux)*/
baliseA ~ baliseB { proprieter : valeur; }

/*Avec une balise + classe*/
baliseA .class { proprieter: valeur; }

/*Avec balise + id*/
baliseA #id { proprieter : valeur; }

/*Universel (tous les éléments)*/
* { proprieter : valeur; }

/*Balise avec attribut*/
baliseA [attribut] { proprieter : valeur; }

/*Balise avec attribut + valeur*/
baliseA [attribut= valeur] { proprieter : valeur; }

/*Pseudo-classe (au survol) souris sur l'élément*/
a:hover { proprieter: valeur; }

/*Pseudo-classe (au clic) clic en cours*/
a:active { proprieter : valeur; }

/*Pseudo-classe élément sélectionné "change"*/
a:focus { proprieter : valeur; }

/*Pseudo-classe lien déjà visité*/
a:visited { proprieter : valeur; }

/*Pseudo-élément première ligne texte en gras*/
a::first-line { font-weight : bold; }
```

## Ordre de priorité

```
/*─── Schéma de spécificité CSS (du + faible au + fort) ───*/

Poids 0    →  *              (universel)
Poids 001  →  balise         (ex: p, h1)
Poids 002  →  balise balise  (ex: section h1)
Poids 010  →  .class
Poids 011  →  balise.class   (ex: h1.titre)
Poids 012  →  balise balise.class
Poids 100  →  #id
Poids 101  →  balise#id
Poids 110  →  .class #id
Poids 1000 →  style="" ou !important  ← PRIORITÉ ABSOLUE
```

| Sélecteur | Nb d’identifiants | Nb de classes | Nb d’éléments | Poids total |
| --- | --- | --- | --- | --- |
| `*` | 0 | 0 | 0 | 0 |
| `a {}` | 0 | 0 | 1 | 001 |
| `section h1 {}` | 0 | 0 | 2 | 002 |
| `.class {}` | 0 | 1 | 0 | 010 |
| `h1.class {}` | 0 | 1 | 1 | 011 |
| `Section h1.p {}` | 0 | 1 | 2 | 012 |
| `#id {}` | 1 | 0 | 0 | 100 |
| `h1#id {}` | 1 | 0 | 1 | 101 |
| `.class #id {}` | 1 | 1 | 0 | 110 |
| `style=""` ou `!important` | 1 | 0 | 0 | 1000 |
| `p { color:red !important; }` | 1 | 0 | 1 | 1001 |

## Héritage 📌

```
/*─── Schéma héritage CSS ───*/

                <html>
                  │
                <body>           ← hérite de html
               /      \
          <header>    <main>     ← héritent de body
             │           │
           <nav>      <section>  ← héritent de header/main

✅ Propriétés héritées par défaut :
   → Textes / Typographie (color, font-size, font-family...)
   → Listes (partiellement)
   → Tableaux (limités)

❌ Propriétés NON héritées par défaut :
   → Boîtes (padding, margin, border)
   → Positionnement (position, top, left...)
   → Visuel (background, opacity...)
   → Dimensions (width, height)
```

## Import de police 📌

### Local

1. Télécharger la police sur le web
2. Placer les fichiers dans le dossier `assets/fonts/`
3. Déclarer la police en tête du fichier `.css`
4. Utiliser la police

```css
@font-face {
  font-family: "MaPolice";
  src: url("/assets/fonts/mapolice.woff2") format("woff2"),
       url("/assets/fonts/mapolice.woff") format("woff");
}

body {
  font-family: "MaPolice", sans-serif;
}
```

### Google Fonts

1. Choisir la police et son style sur le site
2. Copier le lien import `@import`
3. Déclarer en tête du fichier `.css`
4. Utiliser la police

```css
@import url("https://fonts.googleapis.com/css2?family=Roboto&display=swap");

body {
  font-family: "Roboto", sans-serif;
}
```

## Structure nommage des classes BEM (class=““) 📌

```
/*─── Schéma BEM ───*/

.bloc                    → Composant principal
.bloc__element           → Sous-partie du bloc
.bloc--modifier          → Variation du composant
.bloc__element--modifier → Variation d'un élément

Exemple :
.carte                   → Le composant carte
.carte__titre            → Le titre de la carte
.carte--highlight        → Variante carte surlignée
.carte__titre--small     → Variante petit titre
```

## Flexbox 📌

> Permet de distribuer et aligner des éléments flexibles dans un conteneur (`<div>`, `<section>`, `<article>`…), même si leur taille change.
> 

```
/*─── Schéma Flexbox ───*/

  flex-direction: row (par défaut)
  ◄────── axe principal (horizontal) ──────►

  ┌────────────────────────────────────────┐
  │  justify-content → axe horizontal      │  ▲
  │                                        │  │ align-items
  │  ┌──────┐  ┌──────┐  ┌──────┐          │  │ (axe vertical)
  │  │  1   │  │  2   │  │  3   │          │  ▼
  │  └──────┘  └──────┘  └──────┘          │
  └────────────────────────────────────────┘

  flex-direction: column
  ┌──────────┐   ▲ justify-content (axe vertical)
  │    1     │
  ├──────────┤
  │    2     │  ◄─► align-items (axe horizontal)
  ├──────────┤
  │    3     │
  └──────────┘
```

```css
.container { display: flex; }

/* justify-content (axe horizontal) */
.container { display: flex; justify-content: flex-start; }
.container { display: flex; justify-content: center; }
.container { display: flex; justify-content: flex-end; }
.container { display: flex; justify-content: space-between; }
.container { display: flex; justify-content: space-around; }
.container { display: flex; justify-content: space-evenly; }

/* align-items (axe vertical) */
.container { display: flex; align-items: flex-start; }
.container { display: flex; align-items: center; }
.container { display: flex; align-items: flex-end; }
.container { display: flex; align-items: stretch; }

/* flex-direction */
.container { display: flex; flex-direction: row; }
.container { display: flex; flex-direction: row-reverse; }
.container { display: flex; flex-direction: column; }
.container { display: flex; flex-direction: column-reverse; }

/* flex-wrap */
.container { display: flex; flex-wrap: nowrap; }
.container { display: flex; flex-flow: row wrap; }

/* Ordre */
.first  { order: -1; }
.third  { order: 2; }
.fifth  { order: 3; }

/* Taille */
.item { flex-grow: 1; }
.item { flex-shrink: 1; }
.item { flex-basis: 200px; }
```

## Grid 📌

> Permet de distribuer et aligner des éléments dans un conteneur (`<div>`, `<main>`, `<footer>`…), de façon plus puissante que Flexbox.
> 

```
/*─── Schéma Grid CSS ───*/

  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 100px 100px;

  col 1       col 2       col 3
  ┌───────────┬───────────┬───────────┐
  │  item 1   │  item 2   │  item 3   │  ← ligne 1
  ├───────────┼───────────┼───────────┤
  │  item 4   │  item 5   │  item 6   │  ← ligne 2
  └───────────┴───────────┴───────────┘
       ↕ row-gap        ↔ column-gap

  grid-template-areas :
  ┌─────────────────────────────────┐
  │             header              │
  ├───────────────────┬─────────────┤
  │       main        │    aside    │
  ├───────────────────┴─────────────┤
  │             footer              │
  └─────────────────────────────────┘
```

```css
.container { display: grid; }
.container { display: inline-grid; }

.container { display: grid; grid-template-columns: px px fr; }
.container { display: grid; grid-template-rows: px px px; }

.container {
  display: grid;
  grid-template-areas: "header nav";
}
.header { grid-area: header; }
.nav    { grid-area: nav; }

.container { display: grid; column-gap: px; }
.container { display: grid; row-gap: px; }
.container { display: grid; gap: px; }

.container { display: grid; grid-auto-columns: px; }
.container { display: grid; grid-auto-rows: px; }
.container { display: grid; grid-auto-flow: valeur; }

.container { display: grid; justify-items: valeur; }
.container { display: grid; align-items: valeur; }
.container { display: grid; justify-content: valeur; }
.container { display: grid; align-content: valeur; height: px; }

.item { grid-column-start: 2; }
.item { grid-column-end: 3; }
.item { grid-row-start: 2; }
.item { grid-row-end: 3; }
.item { grid-column: 2; }
.item { grid-row: 2; }
.item { grid-area: 1/1/3/3; }

.item { justify-self: valeur; }
.container { display: grid; align-content: valeur; height: 300px; }
.container { display: grid; justify-content: valeur; width: 500px; }
```

```
  ┌─────────┬───────────┬───────────┬───────────┬──────────►
```

**Types de media :** `all` / `screen` / `print`

**Conditions :** `width` / `min-width` / `max-width` / `height` / `aspect-ratio` / `orientation` / `résolution`

```css
@media type-media opérateur (condition) {
  /* Style CSS */
}
```

## Pré-processeur (SASS / SCSS)

> Améliore le CSS avec variables, logique et compilation automatique.
> 

```
/*─── Schéma flux SASS → CSS ───*/

  style.scss + _nav.scss + _variables.scss
       │
  Compilation sass style.scss style.css
       │
  style.css  ← fichier final lu par le navigateur
```

**Caractéristiques :**
- **Imbrication** → Hiérarchie code
- **Variables** → Valeurs réutilisables
- **Logiques** → Conditions, boucles
- Code compilé en CSS
- **Sourcemaps** → Lien source et CSS compilé
- Compatible frameworks (Vue, React…) via plugins/loaders
- Compilation automatique (mode watch)
- **Import** → Sépare le code en plusieurs fichiers

**Méthodes SASS :**
- `@extend` → Partage le style entre sélecteurs
- `@mixin` → Crée des styles réutilisables (dupliqués en CSS)
- `@each` → Boucle (répète le code automatiquement)
- Opérations → Calculs CSS (ex: `width: 100%/2`)
- Fonctions → Manipule les couleurs… (ex: `darken()`)

```bash
npm install -g sass
```

```bash
sass style.scss style.css
```

```html
<link rel="stylesheet" href="style.css">
```

### Variables

```scss
$nom-variable : valeur;

button {
  color: $color-primary;
}
```

### Imbrication

```scss
nav {
  propriété: valeur;
  ul { propriété: valeur; }
  a  { propriété: valeur; }
}
```

### Importer une feuille de style

```scss
@use "nav";
```

### Mixins

```scss
@mixin nom-mixin {
  propriété: valeur;
  autre-propriété: autre-valeur;
}

.selecteur {
  @include nom-mixin;
}
```

### Héritage

```scss
.class1 { propriete: valeur; }

.class2 { @extend .class1; }
```

### Boucle

```scss
@each $color in (red, blue, green) {
  .selecteur-#{$color} {
    color: $color;
  }
}
```

## Guide architecture — Feuilles de style gros projet

```
/*─── Schéma architecture CSS ───*/

  style.scss (fichier principal)
  │
  ├── _base.scss         → Reset, typographie, couleurs
  ├── _commons.scss      → Header, Footer, Sidebar, Nav
  ├── _components.scss   → Boutons, Formulaires, Cartes, Modales
  ├── _theme.scss        → Couleurs globales, ombres, identité
  ├── _utilities.scss    → Marges, padding, flexbox, grid
  ├── _overrides.scss    → Surcharge de framework
  ├── _animations.scss   → Transitions, Keyframes, hover
  └── _mediaqueries.scss → Mobile, Tablette, Desktop
```

1. **Feuille de base** → Reset/Normalize CSS, typographie, couleurs, styles généraux
2. **Feuille des parties communes** → Header, Footer, Sidebar, Navigation principale
3. **Feuille des composants** → Boutons, Formulaire, Cartes, Modales, Alertes
4. **Feuille de thème** → Couleurs globales, typographie, ombres, identité visuelle
5. **Feuilles des utilitaires** → Marges et padding, Flexbox/Grid, Alignements, Display
6. **Feuille des overrides** → Évite de modifier directement le framework
7. **Feuille des animations** → Transitions, Keyframes, Effets hover
8. **Feuille des media queries** → Mobile, Tablette, Desktop

## Guide architecture de style méthode SMACSS 📌

```
/*─── Schéma SMACSS ───*/

  1. Base     → p { } h1 { } a { }     (styles HTML globaux)
  2. Layout   → .header { } .footer { } (sections communes)
  3. Module   → .btn { } .card { }      (composants réutilisables)
  4. State    → .is-active { }          (états interactifs)
  5. Thème    → .theme-dark { }         (apparence globale)
  6. Vendor   → styles librairies externes
```

1. **Base** → Style aux éléments HTML globaux (`p`, `h1`, `a`, `ul`…)
2. **Mise en page** → Sections communes à toutes pages (header, footer…)
3. **Module** → Composants UI (boutons, cartes, formulaires…)
4. **State** → Modifie l’apparence selon interaction ou état (actif, caché…)
5. **Thème** → Style lié à l’apparence globale (dark mode, couleurs…)
6. **Vendor** → Style venant de bibliothèques externes (framework / outil)

## Guide de conception CSS méthode OOCSS

1. **Composants / bibliothèque d’objets** → Composants UI réutilisables comme objets indépendants
2. **Utilisation des grilles** → Organisation composants par système de grille CSS
3. **Flexibilité des composants** → Styles indépendants et combinables
4. **Classes multiples** → Utilise plusieurs classes sur un même élément
5. **Séparation structure** → Distingue la structure (positionnement) et skin (couleurs, style visuel…)
6. **Indépendance des styles** → Ne pas dépendre de la structure HTML
7. **Classes autonomes** → Favorise classes indépendantes de la hiérarchie HTML
8. **Réduction de la duplication** → Limite la répétition de styles CSS
9. **Réutilisation maximale** → Styles conçus pour être réutilisés dans plusieurs pages

## Guide de style CSS

1. **Base et compatibilité** → `normalize.css` ou `reset.css`, polices via `@font-face`
2. **Organisation globale CSS** → Du global au spécifique, organisation par composants
3. **Structure et architecture** → Découpé en fichiers, styles standardisés, classes utilitaires
4. **Conventions de nommage** → kebab-case, minuscules, pas d’underscore ni camelCase, BEM
5. **Syntaxe et formatage** → `;` obligatoire, espace autour des `:`, indentation 2 espaces, ~80 caractères
6. **Organisation des propriétés** → Regroupement logique (couleurs, effets…)
7. **Sélecteurs CSS** → Max 3 niveaux, éviter sélecteurs lourds, priorité éléments → classes → IDs
8. **Responsive design** → Mobile en 1er, breakpoints centralisés
9. **Couleurs et variables** → CSS variables recommandé
10. **Performance** → Éviter la répétition, minification, concaténation
11. **Position et layout** → `position` avec parcimonie, préférer `min-height`
12. **Unités** → Préférer `rem`, `em`, `%` — éviter `px` (sauf cas fixes)
13. **Accessibilité** → Contrastes suffisants, focus visibles, états interactifs clairs
14. **Compatibilités navigateurs** → Vérifier sur différents appareils
15. **Documentation** → Commenter les parties complexes, `TODO` / `FIXME`
16. **Travail en équipe** → Style guide CSS, conventions partagées
17. **Méthodes avancées** → Centraliser couleurs, espacements, standardiser media queries
18. **Animations** → Transitions simples, éviter animations lourdes ou inutiles
